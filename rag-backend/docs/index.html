AI PDF Chatbot API Documentation

Powered by LangChain and LangGraph

Quick Start

1. Create a Thread

Start by creating a conversation thread to maintain context:

POST /threads { "metadata": { "user": "john_doe" } }

2. Ingest Documents

Upload PDF documents for indexing:

POST /threads/{threadId}/runs { "assistant_id": "ingestion_graph", "input": { "docs": [...] } }

3. Ask Questions

Query the indexed documents:

POST /threads/{threadId}/runs { "assistant_id": "retrieval_graph", "input": { "query": "What is...?" } }

Key Features

🚀 Real-time Streaming

Support for Server-Sent Events (SSE) enables real-time streaming of responses, providing immediate feedback during document processing and question answering.

📚 Vector Storage

Documents are converted to embeddings and stored in vector databases (Supabase, Chroma, Pinecone) for efficient semantic search and retrieval.

🔄 Stateful Conversations

Thread-based architecture maintains conversation context across multiple interactions, enabling coherent multi-turn dialogues.

⚙️ Configurable Models

Flexible configuration supports multiple LLM providers (OpenAI, Anthropic, Azure) and allows runtime parameter adjustments.

Available Endpoints

  • POST/threads - Create a new conversation thread
  • GET/threads - List all threads
  • GET/threads/{threadId} - Get thread details
  • DELETE/threads/{threadId} - Delete a thread
  • POST/threads/{threadId}/runs - Execute ingestion or retrieval
  • GET/threads/{threadId}/runs/{runId} - Get run status
  • GET/threads/{threadId}/state - Get thread state
  • GET/health - Health check

Authentication

The API supports two authentication methods:

  • API Key: Include your API key in the X-API-Key header
  • Bearer Token: Use JWT tokens in the Authorization: Bearer {token} header
